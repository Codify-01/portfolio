# MM | Portfolio

Static portfolio (HTML, CSS, JavaScript). Open `index.html` in a browser.

Files: `index.html`, `style.css`, `script.js`, `assets/` (favicon + CV PDF).

- Colours/fonts: top of `style.css` (`:root`).
- Hover tilt strength: `max` value in `script.js` (degrees).
- Fonts load from Google Fonts when online; system fonts offline.
- Profile photo: `assets/profile.webp` (replace with same name to change).
- Add projects: copy a card in the Projects section of `index.html`.
